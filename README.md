# loan-default-analysis

About the Project

This is a beginner-level data analytics project focused on analyzing loan data and identifying patterns related to loan defaults.

The project uses Excel and SQL (BigQuery) for data preparation and analysis.

Tools Used

- Excel
- SQL
- Google BigQuery

Project Workflow

Excel → CSV → BigQuery → SQL Analysis

What I Did

- Prepared and organized the loan dataset in Excel.
- Converted the dataset into CSV format.
- Uploaded the data into BigQuery.
- Used SQL queries to analyze the dataset.
- Analyzed loan amounts and loan-related information.
- Used aggregate functions such as "SUM()" and "AVG()".
- Used filtering, sorting, grouping, and JOIN operations where required.

SQL Analysis

The project currently contains multiple SQL questions and queries covering different aspects of the loan dataset.

Some of the analysis includes:

- Total loan amount
- Average loan amount
- Number of loans
- Loan default analysis
- Analysis by loan purpose
- Analysis by employment/income groups
- Analysis using customer and loan information
